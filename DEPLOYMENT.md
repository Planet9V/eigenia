# Production Deployment Guide — Eigenia B.V. & Eigenia Labs

This guide provides step-by-step instructions for deploying the **Eigenia** web application using **Docker Containerization** and **Railway Cloud Hosting**.

---

## Option 1: Docker & Docker Compose Deployment

The application includes a multi-stage Dockerfile based on Node.js 20 Alpine for optimized production builds (`standalone` output).

### Step 1: Docker Environment Setup

Ensure Docker and Docker Compose are installed on your host machine or server:

```bash
docker --version
docker compose version
```

### Step 2: Build and Launch Container

Navigate to the `web` application directory and run Docker Compose:

```bash
# Navigate to web directory
cd eigenia/web

# Build container and start in detached mode
docker compose up --build -d
```

### Step 3: Verify Running Container

```bash
# Check container status
docker compose ps

# View container logs
docker compose logs -f
```

The application will be running and listening on port `3000`:
- **Local Access:** `http://localhost:3000`
- **Reverse Proxy / Nginx Setup:** Proxy pass incoming HTTPS traffic on port 443 to `http://127.0.0.1:3000`.

### Step 4: Stopping & Restarting Container

```bash
# Stop containers
docker compose down

# Restart containers
docker compose restart
```

## Option 2: Railway Cloud Deployment

Railway provides seamless containerized hosting with automated SSL certificates, custom domains, and continuous deployment from GitHub.

### Step 1: Push Code to GitHub

Ensure your latest changes are pushed to your GitHub repository (`planet9v/eigenia`).

### Step 2: Create New Project on Railway

1. Log into your [Railway Console](https://railway.app/).
2. Click **+ New Project** → Select **Deploy from GitHub repo**.
3. Select your repository: `planet9v/eigenia`.

### Step 3: Configure Railway Service Settings

1. **Root Directory:** Set Root Directory to `web` (or leave default if deploying root).
2. **Build Settings:**
   - Railway automatically detects the `web/Dockerfile` or Next.js application.
   - **Build Command:** `npm run build`
   - **Start Command:** `node server.js` (or `npm run start`)
3. **Environment Variables:**
   Add the following environment variables in the Railway dashboard:
   - `NODE_ENV` = `production`
   - `PORT` = `3000`
   - `NEXT_TELEMETRY_DISABLED` = `1`

### Step 4: Add Custom Domain

1. In your Railway service dashboard, navigate to **Settings** → **Networking** → **Custom Domains**.
2. Add your custom domain (e.g., `eigenia.nl` or `eigenia.com`).
3. Update your DNS provider (e.g., Cloudflare, TransIP, or Route 53) with the CNAME record generated by Railway.
