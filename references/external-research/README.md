# External research

Sources found via `valyu` (or other external search) to back a claim in a
working-group paper, when the working group's own material in `references/`
didn't already cover it — not the working group's own analysis.

## Naming

One file per source: `<WG-code>_<topic-slug>_<YYYYMMDD>.md`, e.g.
`WG-07-TM_kramers-escape-rate_20260812.md`. The WG-code prefix ties the
source back to the working-group folder it supports.

## Each file should contain

- Title
- The query that found it
- Source / URL / DOI
- Retrieval date
- Which paper or WG doc uses it
- A short summary
