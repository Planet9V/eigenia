Or merge straight in, since it fast-forwards:

    git checkout main && git merge --ff-only mpn/series-v2 && git push origin main

**`--ff-only` is the safety.** If anything has landed on `main` since `585eb55` the merge refuses rather than rewriting, and the branch can be rebuilt on the newer tip.
