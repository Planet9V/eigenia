## Table 2: Asset → Certification Status → Gap Description

ISASecure certification status per ISCI Certified Products Registry (2025-06-13). Gap descriptions reference specific IEC 62443-4-2 CRs unfulfilled at the SL-3 or SL-4 target.

| Asset | ISASecure Certification Status | Gap Description (SL-3/SL-4 non-compliance) |
|:---|:---|:---|
| **AI/ML System** | **No certification pathway exists.** IEC 62443-4-2 Clause 6 defines four component types (Embedded Device, Network Component, Host Device, Software Application). No component type explicitly covers ML model integrity, training data provenance, or decision boundary verification. The AI system cannot be certified to IEC 62443-4-2. | **Critical gap.** The AI system requires CR 3.4 (software & information integrity) extended to cover model file integrity, CR 3.7 (input validation) extended to cover adversarial input detection, and CR 2.8 (auditable events) extended to log every inference decision with model version hash. No vendor in the ISASecure registry offers AI/ML component certification. |
